# 夏の絵日記メーカー (picture-diary)

「夏」をテーマに、昔懐かしい「絵日記」を、ブラウザ上で作成・保存できるWebページです。

---
## 公開URL
- **Webページ**: https://rk72326.github.io/picture-diary/
- **テストページ**: https://rk72326.github.io/picture-diary/test/test.html
  
---

## 主な機能
- **お絵描きキャンバス**: 描画ツール（ペン・消しゴム）を使ったお絵描きができます。
- **お絵描き補助ツール**: 12色のカラーパレットとツールの太さを変更するスライダー、Undo機能と全消し機能があります。
- **夏の風物詩スタンプ**: 選択してキャンバス上をクリックすると、スタンプが配置されます。
- **日付・天気入力**: 日付は年月日を、天気は[はれ、くもり、あめ、ゆき]から選択できます。
- **日記入力**: 最大9行まで入力できます。9行以上入力すると、9行目末尾まで入力が戻ります。
- **画像合成エクスポート**: キャンバス、日付・天気、本文を一枚のPNG画像として合成し、保存します。
